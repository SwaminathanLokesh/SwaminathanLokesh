I'm a **B.Tech Computer Science graduate (2026, SASTRA Deemed University)** who builds machine learning systems that are accurate and explainable, from raw data to a working product. I focus on evaluation (F1, AUC, error analysis) and explainability, because a model nobody trusts does not get used.

- 🔭 Currently building **Generative AI apps** with LangChain, RAG and vector databases
- 🧠 Strong foundation in **machine learning and deep learning**, with hands-on recommender systems, churn prediction and explainable AI work
- 🌐 Comfortable with **full-stack development** (MERN) and shipping a feature end to end
- 🌱 Learning: LLM application development, system design and advanced DSA
- 💬 Ask me about: machine learning, recommender systems, RAG chatbots, SHAP and the MERN stack
